# تقرير MR_AMWAL الصباحي على واتساب

يعمل على سيرفر GitHub المجاني كل يوم الساعة 7:00 صباحاً بتوقيت عمّان، حتى لو كان جهازك مطفأً.
يجلب الأسعار الحقيقية (CoinGecko وYahoo Finance)، يصمّم بطاقة التقرير بهوية MR_AMWAL، ويرسلها صورةً إلى محادثتك مع نفسك.

## الإعداد (مرة واحدة)

1. **ارفع الملفات** إلى المستودع: مجلد `whatsapp-report` كاملاً، وملف `.github/workflows/whatsapp-report.yml`.
2. **أضف الأسرار** من Settings ← Secrets and variables ← Actions ← New repository secret:
   - `WHATSAPP_PHONE` : رقمك بالصيغة الدولية بدون + ولا مسافات، مثل `9627XXXXXXXX`
   - `SESSION_KEY` : أي جملة طويلة عشوائية (كلمة سر لتشفير جلسة واتساب)
   - `GEMINI_API_KEY` : اختياري. مفتاح مجاني من aistudio.google.com يضيف 3 أخبار عربية للبطاقة. بدونه تكون البطاقة أسعاراً ومؤشرات فقط.
3. **اربط واتساب**: Actions ← WhatsApp Morning Report ← Run workflow ← اختر `pair` ← Run.
   افتح التشغيل، ثم خطوة "Run (pair)"، وانتظر حتى يظهر رمز من 8 أحرف.
   على جوالك: واتساب ← الأجهزة المرتبطة ← ربط جهاز ← **الربط برقم الهاتف بدلاً من ذلك** ← أدخل الرمز.
   ستصلك رسالة تأكيد على واتساب، وتُحفظ الجلسة مشفّرة في المستودع.
4. **جرّب الإرسال**: Run workflow ← `send`. يجب أن تصلك البطاقة خلال دقيقتين.

بعدها يعمل تلقائياً كل صباح.

## إذا توقف
- إذا فصل واتساب الجهاز المرتبط، شغّل `pair` مرة أخرى.
- سجل كل تشغيل موجود في Actions، وفيه سبب أي خطأ.
